AnonyCopies

Anonymisation de copies d’élèves et d’étudiants avant envoi à une IA. Tout se passe dans votre navigateur : vos copies ne sont jamais envoyées sur Internet.
❓ Aide : comment utiliser AnonyCopies ?

En 5 étapes

  1. Chargez les PDF des copies (glisser-déposer ou clic).
  2. Cliquez une copie dans le tableau, puis tracez à la souris un rectangle sur chaque endroit où le nom apparaît. Plusieurs zones et plusieurs pages sont possibles (boutons ◀ ▶). La 1re zone reçoit le numéro.
  3. Nom et prénom (facultatif) : si le PDF contient du texte, les cases se remplissent seules. Nom et prénom sur deux lignes : 1re sélection → nom, 2e → prénom. Sinon, saisissez-les à la main ou laissez vide.
  4. Réglez la numérotation (ordre aléatoire recommandé) puis cliquez Anonymiser.
  5. Téléchargez le ZIP des copies anonymes (à envoyer à l’IA) et le CSV de correspondance (à garder pour vous, jamais avec les copies).

Bon à savoir

  • Gabarit identique ? Tracez la zone sur une copie puis cliquez « Copier ces zones vers les copies sans zone » : elle est recopiée sur celles qui n’en ont pas encore, sans toucher aux autres.
  • « Trouvé dans » indique si le nom, le prénom ou les deux figurent dans le nom du fichier ou les métadonnées. Dans les copies produites, le nom de fichier est remplacé (Copie_017.pdf) et ces métadonnées sont supprimées.
  • Sans zone, la copie est quand même traitée : le numéro est placé en haut à gauche de la page 1, mais rien ne masque le nom s’il est écrit sur la copie.
  • Les zones sont noircies définitivement ; le reste du texte est conservé, donc le PDF reste lisible par une IA. Les copies scannées ou manuscrites restent des images (pas de texte extractible).
  • Vos fichiers ne sont envoyés nulle part. Seules les bibliothèques de l’outil sont chargées depuis Internet au démarrage.
  • Cet outil pseudonymise : le CSV permet de ré-identifier les élèves, protégez-le. Vérifiez aussi qu’aucun prénom, numéro d’étudiant ou signature ne reste dans le corps des copies, et testez d’abord sur quelques copies.
